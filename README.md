🩸 LifeLine — Every Drop Counts

Connecting Blood Donors with Those in Need

LifeLine is a modern blood donation platform designed to connect blood donors with people who urgently need blood. Its mission is to make blood donation more accessible, improve communication between donors and recipients, and help save lives through faster connections.

---

🌟 About the Project

LifeLine is a web-based platform that simplifies the process of finding blood donors and connecting them with people in need.

The platform aims to create a community where donors and recipients can connect efficiently, helping reduce delays in emergency situations.

🎯 Project Goals

- Connect blood donors with people who need blood.
- Make it easier to find donors based on blood type and location.
- Encourage voluntary blood donation.
- Raise awareness about the importance of donating blood.
- Support faster communication during blood emergencies.

✨ Features

- 🩸 Blood Donor Search
- 📍 Location-Based Search
- 🤝 Donor Registration
- 🚨 Emergency Blood Requests
- 📱 Responsive Design
- 🌙 Dark & Light Mode
- 💻 Modern and User-Friendly Interface

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

🚀 Getting Started

1. Clone the repository:
   
   "git clone YOUR_REPOSITORY_URL"

2. Open the project folder in Visual Studio Code.

3. Run "index.html" using Live Server or your preferred browser.
