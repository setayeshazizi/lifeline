Trust & Safety

Built around trust.

Principles that guide how this demo platform is designed — and how a real one should be.

Privacy-First Design

Donor details stay in your browser in this demo — no accounts, no servers, no tracking.

Transparent Information

Every request shows its type, amount, component and urgency clearly — demo data is always labeled as fictional.

Clear Emergency Status

Critical, urgent and normal requests are visually distinct, so real emergencies never blend in.

Responsible Data Handling

Only sample data is ever used here — never real patient or medical information.
